# mutual-funds

Fatail Singh's research on capital-growth mutual funds using the fat-tail approach: a small number of big winners drive most long-run gains, so the work is to find, watch and shortlist those funds early.

This is not investment advice. Nothing here is an offer, a recommendation, or a decision to buy or sell any fund. Vipul Anand decides; agents research, check, record and propose.

## Core idea

- [`capgrowfat.md`](capgrowfat.md) is the core-idea reference: a transcript on power laws and fat tails in market returns.

## Method and public records

- [`method/method-manual.md`](method/method-manual.md) — how the fat-tail test works, the data sources, the caveats, and the research cadence.
- [`method/fund-metrics-format.md`](method/fund-metrics-format.md) — the column layout for published fund-metrics files (comma-separated values).
- [`templates/weekly-report.md`](templates/weekly-report.md) — the template for each weekly public report.

## What is public and what is private

This repository is public. It holds only:

- the method
- fund-level metrics
- weekly reports

A private Google Sheet holds:

- blind calls
- state of mind
- the near-miss ledger

This repository never holds personal amounts, holdings, folio numbers, Permanent Account Number (PAN) details, or bank or account details.
